# Looprgh

Queue management software for banks, clinics and shops: digital tickets, live wait times, kiosk check-in and a staff dashboard.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
